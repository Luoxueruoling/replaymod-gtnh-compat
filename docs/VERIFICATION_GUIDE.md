# ReplayMod GTNH 适配包 · 复查方法（通用版）

> 这份文档回答四件事：**怎么装、每一项怎么验、出问题要给我什么、我怎么判读**。
> 它**不绑定版本**，每次拿到新包都按这份走；包里自带的那份 `本次要测什么.md` 只说明"这一版新改了什么"。
> 上游背景：官方 ReplayMod 在 `1.7.10` 上问题很多，本适配包是一系列针对性修补；
> 因此**每一条修复都必须逐项复验**，不能只看"游戏能开"。

---

## 2. 装包（3 步，别省）

1. 打开实例的 **`mods`** 文件夹；
2. **删掉**旧的 `replaymod-*.jar`（官方的 `replaymod-1.7.10-2.5.2.jar` 也删）；
   > ⚠️ 两个 ReplayMod 同时存在会冲突，画面会错乱 —— 这不是本包的问题。
3. 把新包放进去，重启游戏。

**校验**：`Get-FileHash .\replaymod-....jar -Algorithm SHA256` 应与包内 `SHA256.txt` 一致。

## 3. 逐项复查表（★ 每次都要走完，逐项记"过 / 没过 / 没条件试"）

> 打勾的项说明"已经验证过并稳定"，但仍建议快速回归；带 ★ 的是容易出问题、判据最硬的项。

| # | 项 | 怎么做 | 期望 | 硬判据（日志 / 画面） |
|---|---|---|---|---|
| 1 | **主菜单入口** | 启动到主菜单 | 右上角出现中文「回放中心」按钮 | 日志 `ReplayMod main menu button added at …` |
| 2 | **打开回放不崩** | 回放中心里点「加载」 | 正常进入回放界面 | 无 `crash-reports\` 新文件 |
| 3 | **回放里能看到玩家** | 打开录像后看画面 | 一打开就能看到玩家实体（**不需要**切维度） | 日志 `holding S0CPacketSpawnPlayer …` 后紧跟 `re-queued N deferred packet(s)` |
| 4 | ★ **自由相机** | 打开回放后**什么都不点**，按 `WASD` | 是自由飞行的回放相机，**不是**某人第一人称 | 镜头能自由飞；画面里无"自己的手" |
| 5 | ★ **Ctrl 鼠标锁（不循环）** | 按一下左 `Ctrl` | 鼠标稳稳可用；**再按一次**抓回 | 日志同一秒内 `replay mouse RELEASED` **≤ 1 次**（十几次 = 循环仍在） |

| 7 | ★ **ESC 后时间轴不动** | 按 `ESC` 开菜单、再 `ESC` 关掉 | 播放头**保持原处**（不应跳到中间） | 关菜单后播放头位置不变 |
| 8 | **放开鼠标点界面不崩** | Ctrl 放开鼠标后随便点、随便拖 | 不崩 | 无 `Unreported exception` / 无新 crash |
| 9 | ★ **WASD 可用** | 先 Ctrl 抓回鼠标，再按 `WASD` | 能自由飞行 | 飞得动（**注意：鼠标可见时 WASD 本来就不驱动相机，这是设计**） |
| 10 | ★ **导出渲染：画面正确** | 回放里点「渲染录像」（左侧第 2 个图标）→ 渲染一小段 | 视频**画面有世界**、不白屏、**画面在动** | 抽帧看画面；用第 4 节的"帧量化"两条命令 |

| 12 | ★ **换视角不崩** | 回放里点一个玩家 → 换视角（**最好挑有夜视的目标**） | 切过去、不崩 | 无 `[Client thread/FATAL]: Unreported exception thrown!` |
| 13 | **保存录像面板** | 进世界 20~30 秒后退出世界 → 回主菜单 | 右上角出现保存面板，能改名、点「完成」后文件归位 | 暂存文件从 `replay_recordings\recording\` 移到 `replay_recordings\` |

## 4. ★ 取证规范（最容易做错的地方）

1. **日志要 `logs/fml-client-latest.log`**（或 `dsh-stdout.log`）。
   > **不要给 `logs/latest.log`** —— 我们的补丁输出走 `System.out`，只会出现在前者（带 `[STDOUT]` 前缀）。
   > 给错日志 = 我看不到任何判据，等于白跑一轮。
2. **画面问题要 `F3` 截图**，最好**同一处两张**（例如把播放头拖到 `00:00` 与拖到出问题处各一张）。
   F3 能一次给出：相机坐标 `XYZ`、加载的 chunk 数、当前观察实体、雾/渲染距离 —— 这些是我判断"机位问题"还是"世界真的没渲染"的唯一依据。
3. **视频问题给原文件**（不要截图/转码）。我这边会用两条命令量化：

   ```powershell
   # 时长 / 分辨率 / 帧率
   ffmpeg -i <video.mp4> 2>&1 | Select-String 'Duration|Stream #0.*Video'
   # 逐帧哈希：找"完全重复的帧"（画面冻结 / 循环）
   ffmpeg -i <video.mp4> -f framemd5 -
   # 帧间差分：每帧与上一帧的平均亮度差（判断"画面到底动没动"）
   ffmpeg -i <video.mp4> -vf "tblend=all_mode=difference,signalstats,metadata=print:file=-" -f null -
   ```
4. **描述要分段**：一件现象一段，写清"操作 → 现象 → 是否每次都这样"。**"还是不行"这种描述我无法定位。**
5. **每次反馈附环境卡片**（第 1 节）。

## 5. 判读表（现象 → 结论 → 下一步）

| 日志里看到 | 结论 | 下一步 |
|---|---|---|
| 同一秒出现多次 `replay mouse RELEASED` | 鼠标锁在被反复覆盖 = **循环** | 记录次数；若 > 1/秒，说明修复未生效 |
| `input strobing, switching disabled` | 撞上了防抖动保护（每秒 6 次上限） | 同上 |
| `input screen closed while locked - keeping the mouse visible` | 修复**正在工作**（输入屏关闭时没让锁被偷走） | 正常 |
| `re-queued N deferred packet(s)` | 加载期被暂存的包已重放 | 正常；若只有 `holding` 没有 `re-queued`，玩家就不会出现 |
| `video export: PBO frame capture disabled` | 导出走在"非 PBO"路径上 | 正常（这是修白屏的那条路） |
| `video export: glReadPixels(long) resolved on …` | 走的是 PBO + 反射兜底路径 | 出现它说明非 PBO 那条没生效 |
| `Mixin apply for mod replaymod failed` / `InvalidInjectionException` | **某个补丁没注入**（解析期静默失败） | **必须报告**，附完整那一段 |
| `NoSuchMethodError` | Angelica 缺某个 GL 重载 | 必须报告 |
| 没有任何 `[replaycompat]` 行 | 补丁**完全没跑**（或日志给错了） | 先确认给的是 `fml-client-latest.log` |

## 6. 已知的"不是 bug"（不用报）

- **回放里仍显示原版血条**（以及 JourneyMap 小地图、InGameInfoXML 面板）：GTNH 不发对应事件 / 那两个 mod 自己画的，**已确认无法在本环境修**。
- **回放界面里滚轮「没反应」**：上游在回放界面里**没有绑定滚轮**（滚轮只作用于可滚动列表；速度是滑块，不吃滚轮）。
  若希望「滚轮调速」，那是**新增功能**，跟我们说一声即可。
- **鼠标可见时 `WASD` 不驱动相机**：ReplayMod 的设计（鼠标可见 = 操作界面，抓取 = 控制相机）。想飞就**先按一次 Ctrl 抓回**。
- **刚打开回放、相机贴人物时近处发黑/发白**：回放初始机位的现象，移动相机即正常。
- **不支持"深度图"导出**（OpenEXR 序列）；普通 mp4 / webm / mkv / PNG 序列都正常。
- **导出渲染比原版慢一些**：这是"改走同步读回以保证画面正确"的代价。

## 7. 已知未决问题（有专用判据，请按判据取证）

| 问题 | 专用判据 |
|---|---|
| **回放/渲染里"只剩天空"，看不到世界** | 把播放头**拖到 `00:00`** 与**拖到出问题处**，**各截一张 F3**。→ 若 `00:00` 有世界、只在中段没有：那是**机位在高空**，不是缺陷；若两处都没有：**世界真的没渲染**，我继续挖 |
| **按 `ESC` 后时间轴跑到中间** | 关菜单后看播放头位置；附 `fml-client-latest.log`（我要看那一刻输入屏有没有被重建），并说明**按 ESC 时鼠标是否停在屏幕中央** |
| **时间轴拖不动 / 点一下跳到末尾** | 见第 3 节第 6 项；附日志里的 `RELEASED` / `GRABBED` 计数 |

## 8. 回滚

删掉本包、把原来的 `replaymod-*.jar` 放回去即可 ——
**本包不修改任何配置文件、不写入注册表、不在 mods 之外留下东西**（唯一例外是它自己的录像与导出文件：
`replay_recordings\`、`replay_videos\`）。
